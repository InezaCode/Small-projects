# First-projects

Welcome to my collection of small Python projects! This repository documents my journey of learning Python through hands-on practice and building useful, beginner-friendly applications.

 Projects: 

1. Calculator
A simple calculator that performs basic arithmetic operations, including addition, subtraction, multiplication, and division.

2. Number Guessing Game
An interactive game where the player tries to guess a randomly generated number within a limited number of attempts. It provides hints to help the player guess correctly.

3. To-Do List
A terminal-based task manager that allows users to add tasks, view their list, mark tasks as completed, and delete tasks.

4. Business Expense Tracker
A terminal application for managing business expenses. Users can add, view, and delete expenses, calculate total spending, and view spending totals by category. It supports USD, EUR, and RWF currencies.

🎯 My Goal
My goal is to improve my programming skills by building practical projects, learning new concepts, solving problems, and gradually progressing toward more advanced applications.

This repository will continue to grow as I learn and build more projects! 🚀
